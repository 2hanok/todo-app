## 3. 설계 (Design)

### 3-1. 상태 추가 (`script.js`)

```js
let sortKey   = 'created';   // created | due | priority | text
let sortDir   = 'asc';       // asc | desc (헤더 클릭 시 토글)
let dueFilter = '';          // '' | today | week | overdue
let pinOverdue = false;
const PREFS_KEY = 'todos-v2-prefs';   // 정렬·필터·고정 선택값 저장
```

- 데이터 스키마 `todos-v2`는 변경하지 않음(마이그레이션 불필요).

### 3-2. 날짜 (#3)

- `localDateStr(d = new Date())` → 로컬 `YYYY-MM-DD` (`getFullYear/getMonth/getDate` 조합)
- `todayStr()`은 `localDateStr()` 호출로 교체
- `weekEndStr()` → 오늘 기준 이번 주 일요일(월~일 주간)
- 자정 감시: 다음 자정까지 `setTimeout` → `renderTodos()` 후 재예약, `visibilitychange`에서 날짜 비교

### 3-3. 정렬·빠른필터 (#2)

- `getFiltered()`에 `dueFilter` 조건 추가 (마감일 없는 항목은 기간 필터에서 제외)
- `getSorted(list)`:
  - created: `createdAt`/`id` 순
  - due: 마감일 오름차순, 마감일 없음은 항상 맨 뒤
  - priority: 긴급(0) → 보통(1) → 낮음(2), 동률은 마감일 → 등록순
  - text: `localeCompare('ko')`
  - `pinOverdue`이면 마감 초과 항목을 앞으로(안정 정렬)
- UI: 툴바에 정렬 select + 빠른필터 탭 + "마감 초과 상단 고정" 체크박스, 헤더 `th[data-sort]` 클릭 시 정렬 + 방향 표시(▲▼)

### 3-4. 편집 (#4)

- `startEdit(id)`: 동시에 한 행만 편집(`editingId`), 행 셀을 입력 컨트롤로 교체
  - 텍스트 input, 카테고리·우선순위 select, 마감일 date, 저장/취소 버튼
- `finish(save)`: `done` 플래그로 1회만 실행 → blur·Esc·Enter·버튼 중복 호출 차단
- Esc = 취소(원문 유지), Enter = 저장, 행 바깥 클릭(`focusout` + `relatedTarget`가 행 밖) = 저장
- 빈 텍스트 저장 시 기존 텍스트 유지

### 3-5. 삭제 Undo·확인 (#5)

- `deleteTodo(id)`: 삭제 전 `{item, index}` 스냅샷 → 토스트 "삭제됨 · 실행 취소"
- `clearCompleted()`: `confirm("완료된 할 일 N개를 삭제할까요?")` → 승인 시 삭제 + 토스트 "N개 삭제됨 · 실행 취소"
- `showUndo(message, restoreFn)`: 단일 토스트(새 삭제 시 이전 Undo 확정), 5초 후 자동 소멸
- 복구 시 원래 인덱스로 `splice` 삽입 → `saveTodos()` → `renderTodos()`

### 3-6. 문서 (#1)

- `docs/ARCHITECTURE.md`: #1 구성도·흐름도를 v1.1 기준으로 갱신(정렬·필터 파이프라인, 편집 상태도, Undo 흐름 추가)
- `PRD.md`: 실제 구현(3파일 구조, 우선순위·마감일·검색·요약카드) + v1.1 기능 반영
- `PLAN.md`: 초기 구현 계획(이력)으로 유지, 상단에 PDCA 문서 링크 추가
